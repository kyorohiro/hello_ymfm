3. VGI形式ファイル（.vgi）のデータ仕様（43バイト固定長）
--------------------------------------------------------------------------------
VGIは「VGM Music Maker」で採用されたFM/PSG用音色フォーマットです。
ファイルはヘッダーなしの計43バイトで構成され、YM2612のレジスタ値が格納されています。

【データマップ（オフセット：16進数）】
00: アルゴリズム (ALGO: 接続形式) ＆ フィードバック (FB)
01: LFO設定（FMS, AMS）
02: 音色タイプフラグ（0 = YM2612 FM / 1 = SN76489 PSG）
03〜06: DT (デチューン) / MULTI (倍率) [各オペレーター 1〜4]
07〜0A: TL (Total Level: 音量/変調度) [各オペレーター 1〜4]
0B〜0E: AR (Attack Rate) / RS (Rate Scaling) [各オペレーター 1〜4]
0F〜12: DR (Decay Rate) / AMフラグ [各オペレーター 1〜4]
13〜16: SR (Sustain Rate) [各オペレーター 1〜4]
17〜1A: SL (Sustain Level) / RR (Release Rate) [各オペレーター 1〜4]
1B〜1E: SSG-EG パラメーター [各オペレーター 1〜4]
1F〜2A: 拡張設定・予備領域（ソフトウェア独自のエンベロープ等、12バイト）

4. 他形式（TFI/OPM）から VGI 形式へ一括・個別変換する方法
--------------------------------------------------------------------------------
無料のオープンソースマルチトラッカー「Furnace」を使うことで、VGIに変換可能です。

【変換手順】
1. GitHubから「Furnace」をダウンロードする
   URL: https://github.com
2. Furnaceを起動し、上部メニューの [Song] ＞ [System] から「YM2612 (Sega Mega Drive)」を選択。
3. ダウンロードした「.tfi」や「.opm」ファイルを、Furnaceの画面へ直接ドラッグ＆ドロップして読み込ませる。
4. 画面右上の [Instruments] リストに読み込まれた音色を右クリックし、[Export VGI file...] を選択して保存する。

--------------------------------------------------------------------------------
5. VGM（ゲーム BGM）から自分でダイレクトに VGI を自動抽出する方法
--------------------------------------------------------------------------------
既存の配布パックに頼らず、ゲームのBGMファイル（.vgm）から音色設定を自動解析してVGIとして切り出すツールです。

【手順】
1. メガドライブ音楽のアーカイブサイト「VGMRips」から、目当てのゲームのVGMパックをダウンロードする。
   URL: https://vgmrips.net
2. 音色抽出ツール「VGM2PRE」をダウンロードする。
   URL: https://github.com
   (Win32バイナリ: http://mdscene.net )
3. VGM2PREを起動し、設定で出力フォーマットを「VGI」に指定する。
4. VGMファイルをツールにドラッグ＆ドロップすると、ゲーム内で使用されている全てのFM音源パッチが「.vgi」形式で一括書き出しされます。
