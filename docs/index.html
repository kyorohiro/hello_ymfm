hello_ymfm_wasm demos

Small browser-side demos for YM2612, ymfm, WebAssembly, and VGM parsing.

Repository: https://github.com/kyorohiro/hello_ymfm_wasm

These demos use ymfm by Aaron Giles under the BSD 3-Clause License.

Integration Sample Minimal browser-side sample for app or game embedding with FM SFX, PSG SFX, and VGM playback. Beep Demo Play the same YM2612 beep configuration used in ex03_beep.cpp. Sega PSG Demo Play a minimal Sega PSG / SN76489-compatible tone through WebAssembly. VGM Parser Demo Load a VGM file, inspect the header, and preview parsed YM2612-oriented commands.
