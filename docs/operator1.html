YM2612 1 Operator Demo

This page keeps the setup small: one audible operator, three muted operators, and a few parameters you can change without reading the whole FM algorithm story first.

YM2612 operators use a fixed sine-based waveform. This demo changes the operator settings, not a selectable oscillator shape.
