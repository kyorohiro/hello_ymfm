This page keeps the setup small: one audible operator, three muted operators, and a few parameters you can change without reading the whole FM algorithm story first.

YM2612 operators use a fixed sine-based waveform. This demo changes the operator settings, not a selectable oscillator shape.

What to learn here

This page uses one audible operator so you can study the envelope first before moving to more complex FM setups.

  • TL: how loud this operator is.
  • AR: how fast the sound rises after key on.
  • D1R: how fast it falls from the attack peak.
  • D2R: how fast it keeps falling during the later sustain area.
  • SL: the target level for that later falling stage.
  • RR: how fast it fades after key off.

A useful way to read D2R and SL together is: D2R = speed, SL = destination.
